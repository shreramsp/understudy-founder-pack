**What a reviewer should notice.** Only two arrows cross a boundary, and both are labelled with their payload. Raw frames never leave the workstation as frames — redaction (N4) runs *before* transport, so the pipeline is not "capture then clean" but "clean at capture". The dotted return arrow is the compounding: global procedure shapes flow back *into* stage-1 clustering, which is how environment *n+1* starts warmer than environment *n* (A8). If that arrow carried anything tenant-specific, D6's guarantee would be broken in the direction nobody inspects — inbound.
