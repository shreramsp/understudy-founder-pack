E2's fairness bar has been raised twice

The original design compared against a coordinate-clicking script — a strawman. The second required only "selector-based", which permits fallbacks disabled. The baseline must now be a Unified-Target-equivalent implementation with fuzzy, anchor and image fallbacks enabled. An experiment worth running is one that can lose.
